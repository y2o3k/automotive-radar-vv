# 눈으로 보는 FCW 검증 실습실

Python 3.9 이상과 C 컴파일러 `cc`가 있는 macOS/Linux에서 저장소 루트 기준으로 실행합니다. 추가 Python 패키지는 필요하지 않습니다.

```sh
python3 sil/server.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 종료는 실행한 터미널에서 Ctrl+C입니다. 포트가 사용 중이면 `--port 8766`을 추가하고 해당 주소를 엽니다.

## 첫 실습

1. '앞차에 접근'에서 재생합니다. 처음 거리는 30 m, 상대속도는 -10 m/s입니다.
2. '경계 시점 1.00 s'를 누르면 거리 20 m / TTC 2 s / 경고 ON입니다.
3. 시간 슬라이더를 선택하고 왼쪽 화살표를 한 번 누릅니다. 0.98 s에서는 TTC 2.02 s / OFF입니다.
4. '한 단계 +0.02 s'로 경계가 바뀌는 순간을 확인합니다.
5. 같은 속도와 멀어지는 상황에서 TTC 미계산 / OFF인지 확인합니다.
6. 아래의 기존 CSV 테스트 6개와 실제 C 코드를 함께 읽습니다.

## 실행 구조와 범위

`server.py`가 이상적인 거리와 상대속도를 생성하고, 호스트에서 컴파일한 `fcw.c`에 전달합니다. C 출력으로 TTC와 FCW 상태를 받습니다. 브라우저는 계산된 126개 프레임을 재생합니다. 'C 코드 다시 실행'은 현재 컴파일된 프로그램으로 시나리오와 CSV 6개를 다시 평가합니다. 소스 편집 후에는 서버를 재시작해야 다시 컴파일됩니다.

주행 기대값은 거리 ≤ 접근 속도 × 2라는 요구사항 식으로 독립 계산합니다. 정적 테스트의 기대값은 기존 `testcases/test_cases.csv`에서 읽습니다. TTC 비교 허용오차는 1e-9입니다. 정적 6개 PASS와 주행 프레임 판정은 서로 다른 검사입니다.

이는 경고 기능의 학습용 SIL입니다. 자동 제동 피드백, 실제 레이더 신호, 센서 오차, CAN, ECU, RTOS, 실시간 타이밍, HIL은 구현하지 않았습니다. 20 ms는 가상 시간 간격입니다. 차량 그림 크기는 실제 비율이 아니며, 거리 표시는 흰 점 사이 기준입니다. 모든 주행은 충돌 이전인 2.5 s에 멈춥니다.

## 검사

```sh
python3 -m unittest discover -s tests -v
```

기존 러너 검사 4개와 SIL 검사 4개를 실행합니다. SIL 검사는 실제 C 컴파일 및 실행, 기존 CSV 6개, 0.98/1.00초 경계, 비접근 상황, 비정상 입력 거부를 확인합니다.
