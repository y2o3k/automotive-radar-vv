[고객 요구사항 송부] FCW 기능 사양 v1.0 — 검증 계획 회신 요청

부품사 검증 담당자님께,

귀사 레이더의 FCW(전방충돌경고) 기능에 대해 당사 요구사항을 아래와 같이 송부합니다.
현재 귀사 V0.1은 단일 시점 TTC 판단만 확인된 상태로 보이며, 이 수준으로는 차량 적용 승인이 어렵습니다.
아래 사양 기준으로 검증 계획을 다시 수립해 주십시오.

1. 입력 신호 (주기 50 ms)

| 신호명            | 단위 | 비고                   |
|-------------------|------|------------------------|
| ego_speed         | km/h | 자차 속도              |
| target_valid      | bool | 레이더 타깃 유효 여부  |
| target_range      | m    | 전방 타깃 거리         |
| relative_velocity | m/s  | 음수 = 접근            |

2. 요구사항

- CR-FCW-01 (작동 조건): FCW는 자차 속도 10 km/h ~ 150 km/h 범위에서만 작동한다.
- CR-FCW-02 (경고 진입): TTC 2.0 s 이하 상태가 0.3 s 지속되면 FCW를 ON 한다.
- CR-FCW-03 (경고 해제): FCW ON 상태에서 TTC가 2.5 s를 초과한 상태가 1.0 s 지속되면 OFF 한다.
- CR-FCW-04 (최소 유지): 한 번 ON 된 경고는 최소 1.0 s 유지한다.
- CR-FCW-05 (입력 유효성): target_valid가 FALSE이거나 target_range가 0.5 m ~ 200 m를 벗어나면 경고를 발생시키지 않는다.
- CR-FCW-06 (신호 단절): 입력 신호가 200 ms 이상 수신되지 않으면 경고를 발생시키지 않고 고장 상태로 판단한다.
- CR-FCW-07 (정확도): TTC 계산값은 이론값 대비 ±0.05 s 이내여야 한다.

3. 1차 회신 요청 사항 (코드 수정 전 제출)

1) 요구사항 검토 의견서
   당사 사양에서 해석이 불명확하거나 상충되는 항목이 있으면 질의서로 제출해 주십시오.
   질의 없이 임의 해석으로 진행된 부분은 추후 결함으로 처리합니다.

2) 테스트 사양서 — 각 TC별로 다음 항목을 포함해 주십시오.
   - TC ID / 요구사항 ID 매핑
   - 시험 기법 (경계값, 동등분할 등)
   - 전제 조건
   - 시간에 따른 입력 시퀀스 (단일 값이 아님)
   - 기대 결과 및 Pass/Fail 판정 기준

당사는 테스트 사양서 승인 후에 구현 및 시험 결과를 접수합니다.
커버리지가 부족하거나 판정 기준이 모호하면 반려합니다.
